# Mylamby — правила проекта

## Стек

Next.js (App Router) · TypeScript · Tailwind CSS v4 · Framer Motion (только лёгкие UI-анимации: мобильное меню, Reveal) · Lucide React.

## Команды — запускай в этом порядке перед любым коммитом

```
npm install
npm run lint      # ESLint — сначала
npm run build     # production-сборка — потом
```

Не считай задачу выполненной, пока `lint` и `build` не проходят чисто.

## Источник правды — BRAND_KIT

Этот проект построен по brand kit'у, который владелец бренда предоставил
отдельным документом (PDF/markdown "BRAND_KIT"). Он имеет приоритет над
любыми более ранними черновиками характеристик в истории чата. Если
возникает новое число или факт, которого нет ни в этом файле, ни в
`data/brand-facts.ts` / `data/sizes.ts` — не выдумывай его, помечай как
«уточняется» и спрашивай владельца бренда.

### Бренд

- Название пишется **именно так**: «Mylamby» (заглавная M, остальное
  строчными). Не «MyLamby», не «МАЙЛАМБИ».
- Юрлицо: ООО «ЮГТРАНС» (`siteConfig.legalName`) — обязательно в подвале
  сайта.
- Домен: `mylamby.ru` (`config/site.ts` → `url`).
- Каналы продаж: Wildberries, Ozon (FBO), аптеки и офлайн-розница,
  собственный сайт.

### Подтверждённые характеристики продукта (единственный источник — `data/brand-facts.ts`)

- Абсорбент SAP SANDIA
- 12-слойная конструкция
- Впитывающий слой — 71% состава
- Стандарт качества Japan Quality

Больше в составе ничего нет. Не добавляй «гипоаллергенно», «одобрено
педиатрами», «№1 в России», проценты и слои сверх списка выше — без
документа от владельца бренда.

### Размеры (единственный источник — `data/sizes.ts`)

- Подгузники: NB, S, M, L, XL, XXL.
- Трусики-подгузники: M, L, XL, XXL.
- Количество штук в упаковке по каждому размеру — см. `data/sizes.ts`
  (значения получены напрямую от владельца бренда в переписке, не из
  BRAND_KIT — при расхождении с более новым документом уточни).
- Диапазоны веса ребёнка **не подтверждены нигде** — в `SizeGuide`
  колонка «Вес» показывает «уточняется», а не придуманный диапазон. Не
  заполняй `weightRange` в `data/sizes.ts`, пока не получишь реальные
  цифры.

## Тон голоса (BRAND_KIT §5)

Спокойно, по делу, как опытная подруга — не как рекламный баннер.
Короткие фразы. Конкретные цифры вместо прилагательных.

**Нельзя:** «Невероятный комфорт для вашего малыша!», «Лучшие подгузники
на рынке», «Мы заботимся о вашем ребёнке», восклицательные знаки, эмодзи
в заголовках, слова «инновационный», «premium», «уникальный»,
«революционный», «магия».

**Надо:** «12 слоёв. Впитывающий слой — 71%.», «Абсорбент SAP SANDIA,
стандарт Japan Quality.», «Размеры от NB до XXL.» — конкретные
подтверждённые цифры вместо оценочных прилагательных.

## Жёсткие правила контента

- **Никаких выдуманных данных.** Цены, сертификаты, отзывы, награды,
  сроки доставки, условия возврата, оптовые скидки и минимальные партии
  — не придумывай. Нет данных → честная формулировка («уточняется»,
  «появится здесь», «уточняйте у продавца»), не приблизительное
  значение.
- **Никакого медицинского позиционирования.** Не пиши «лечит опрелости»,
  «рекомендовано врачами», «гипоаллергенно» — это регулируемая
  территория (BRAND_KIT §8).
- **Никаких несуществующих отзывов.** Если отзывов ещё нет — пустой
  блок-слот до появления реальных, не выдуманные цитаты.
- **Никакого фальшивого дефицита.** Без обратного отсчёта, без «осталось
  3 штуки».
- **Никаких сравнений с конкурентами по именам.**
- **Никаких случайных изображений.** Только файлы из
  `public/images/mylamby/`. Логотип — `public/images/mylamby/logo/`,
  фото товаров — `public/images/mylamby/products/`.
- **Шахматная сетка — не прозрачность.** Если PNG/WebP содержит вшитый в
  пиксели шахматный узор вместо настоящего альфа-канала,
  `ProductImageSlot` (через `lib/image-utils.ts`) обязан показать
  нейтральную заглушку, а не клетчатый фон. Предупреждение — только в
  dev-консоли сервера, никогда на экране пользователя.
- **Честные ссылки и кнопки.** Пустая ссылка на маркетплейс или контакт
  (`config/commerce.ts`, `config/contacts.ts`) обязана рендериться как
  отключённая кнопка (`DisabledButton`) с честным текстом — никогда
  `href="#"` и никогда выдуманный номер/адрес/URL.
- **Не выдумывай цену.** Пока в `config/commerce.ts` нет реальной ссылки
  на маркетплейс — не показывай цену; предлагай «Уточнить наличие и
  цену».

## Визуальный стиль (BRAND_KIT §6)

Настроение: светло, чисто, воздушно. Белое пространство. Ощущение
аптеки, а не детского магазина с шариками.

**Запрещено:** мультяшные облачка, сюсюкающие шрифты с закруглениями,
радужные градиенты, кислотные цвета, стоковые младенцы с идеальной
улыбкой на белом фоне, брендовый маскот (в BRAND_KIT маскот не
упомянут — не придумывай его).

### Дизайн-токены (`app/globals.css`, `@theme inline`)

Точное соответствие BRAND_KIT (переименовано только `bg` → `paper`, чтобы
не было класса `bg-bg`; сами значения не менялись):

| Токен Tailwind | Значение | BRAND_KIT |
|---|---|---|
| `paper` | `#FFFFFF` | `--bg` |
| `paper-soft` | `#F6F8FA` | `--bg-soft` |
| `ink` | `#14181F` | `--ink` |
| `ink-muted` | `#5C6675` | `--ink-muted` |
| `accent` | `#3E8FD6` | `--accent` |
| `accent-hover` | `#2F74B0` | `--accent-hover` |
| `accent-soft` | `#E6F1FA` | `--accent-soft` |
| `warm` | `#F3B9A3` | `--warm` (точечный акцент, не фон) |
| `line` | `#E4E8ED` | `--line` |

Радиусы: `rounded-card` = 14px (карточки), `rounded-button` = 10px
(кнопки), `rounded-pill` = 999px (пилюли/бейджи). Тень: `shadow-soft`.

Шрифты: заголовки — Onest 600/700 (`font-display`), текст — Manrope
400/500/600 (`font-sans`). Не вводи новые оттенки/радиусы в компонентах
напрямую — расширяй токены в `globals.css`.

Анимации сдержанные: `components/ui/Reveal.tsx` — лёгкое появление при
скролле (один раз, без прыжков/мигания); карточки — `hover:-translate-y-0.5`
на `transition-transform`.

## Структура

- `app/` — маршруты App Router (главная, контакты, robots/sitemap, 404).
- `components/layout/` — шапка, мобильное меню, футер.
- `components/sections/` — секции главной страницы.
- `components/ui/` — переиспользуемые примитивы (кнопка, карточка
  размера, безопасный слот изображения, Reveal).
- `config/site.ts` — бренд, навигация, домен, юрлицо. `config/commerce.ts`
  — ссылки на маркетплейсы. `config/contacts.ts` — контакты и опт.
- `data/` — типизированные данные (размеры, факты о продукте, FAQ).
- `lib/image-utils.ts` — проверка существования файла и детекция
  запечённой шахматной сетки (переиспользуемая, брендонезависимая).
- `types/` — общие TypeScript-типы.
