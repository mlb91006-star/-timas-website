# TIMAS DH20 Ultra — правила проекта

## Стек

Next.js (App Router) · TypeScript · Tailwind CSS v4 · GSAP + ScrollTrigger ·
Framer Motion (только лёгкие UI-анимации) · Lucide React.

## Команды — запускай в этом порядке перед любым коммитом

```
npm install
npm run lint      # ESLint — сначала
npm run build     # production-сборка — потом
```

Не считай задачу выполненной, пока `lint` и `build` не проходят чисто.

## Подтверждённые характеристики (единственный источник — `data/specifications.ts`)

- тип двигателя: BLDC (бесщёточный);
- мощность: 400 Вт;
- максимальная мощность всасывания: до 30 кПа при полностью заряженном
  аккумуляторе;
- аккумулятор: 29,6 В, 2200 мА·ч, Li-ion, съёмный;
- режимы работы: приблизительно 10, 20, 35 и 60 минут;
- объём контейнера: 800 мл;
- время зарядки: около 5 часов (±30 минут);
- уровень шума: не более 76 дБ;
- моющийся HEPA-фильтр (без заявления класса H11 или процента фильтрации);
- LED-индикатор;
- складная труба;
- моторизированная напольная щётка (без заявления anti-tangle);
- выход адаптера: DC 36 В, 500 мА;
- длина видимого кабеля адаптера: около 150 см (±10%);
- гарантия: 1 год.

## Жёсткие правила контента

- **Никаких выдуманных данных.** Технические характеристики — только из
  `data/specifications.ts`. Не добавляй рейтинги, отзывы, награды,
  количество покупателей, ресурс двигателя в часах, классы фильтрации
  (H11 и т.п.) или anti-tangle — этого нет в подтверждённых данных.
- **Никаких случайных изображений.** Только файлы из `public/images/dh20/`
  и `public/images/dh20/exploded/`. Никогда не подставляй фотографии из
  интернета или чужих брендов.
- **Шахматная сетка — не прозрачность.** Если PNG/WebP содержит вшитый в
  пиксели шахматный узор вместо настоящего альфа-канала, `ProductImageSlot`
  (через `lib/image-utils.ts`) обязан показать нейтральную заглушку, а не
  клетчатый фон. Предупреждение — только в dev-консоли сервера, никогда
  на экране пользователя. Никогда не пытайся вырезать фон через CSS
  blend-mode или замаскировать некачественное изображение — либо
  реальный альфа-канал, либо заглушка.
- **Не выдумывай пропорции деталей.** Пока для детали нет реального
  вырезанного изображения, показывай нейтральный графитовый силуэт
  (уже реализовано в `ProductImageSlot`), а не приблизительно обрезанное
  фото.
- Не копировать напрямую дизайн Apple/Dyson/Samsung/Nothing — у TIMAS
  свой визуальный язык: глубокий чёрный, графитовые секции, акцент
  шампань-металлик.

## Правила анимации (components/product/ExplodedScene.tsx)

- Анимируй только `transform` (x/y/scale/rotate через GSAP) и
  `opacity`/`autoAlpha`. Никогда не анимируй `width`, `height`, `top`,
  `left`, `margin`, `padding`.
- Все координаты, тайминги и тексты — только в `data/exploded-parts.ts`,
  никогда не хардкодь их в JSX.
- Один `gsap.context()` на секцию, cleanup через `ctx.revert()` при
  размонтировании. Никогда не вызывай глобальный `ScrollTrigger.killAll()`.
- Не перехватывай wheel/touch события, не создавай искусственную
  прокрутку.
- Обязательно поддерживай `prefers-reduced-motion` — статичное фото +
  полный список деталей вместо pinned-анимации.

## Структура

- `app/` — маршруты App Router.
- `components/layout/` — шапка, мобильное меню, футер.
- `components/sections/` — секции главной страницы.
- `components/product/` — сцена разборки, страница товара.
- `components/ui/` — переиспользуемые примитивы.
- `config/site.ts` — навигация и мета-конфигурация. `config/commerce.ts`
  — ссылки на покупку (пустые поля → кнопка отключена, никогда `href="#"`).
- `data/` — типизированные данные.
- `hooks/`, `lib/` — общая логика (media query, preload, GSAP, проверка
  изображений).
- `types/` — общие TypeScript-типы.

## Дизайн-токены

Определены в `app/globals.css` (`@theme inline`): `graphite-*` для
секций, `champagne-*` для акцентов, `bone-*` для текста на тёмном фоне.
Не вводи новые оттенки в компонентах напрямую — расширяй токены в
`globals.css`.
