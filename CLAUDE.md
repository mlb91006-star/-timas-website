# TIMAS DH20 Ultra — правила проекта

## Стек

Next.js (App Router) · TypeScript · Tailwind CSS v4 · Framer Motion · GSAP + ScrollTrigger · Lucide React.

## Команды

```
npm install
npm run dev      # разработка
npm run lint      # ESLint
npm run build     # проверка production-сборки
```

## Жёсткие правила контента

- **Никаких выдуманных данных.** Технические характеристики — только из
  `data/specifications.ts`. Не добавляй проценты фильтрации, рейтинги,
  отзывы, награды, количество покупателей — этого нет в подтверждённых
  данных.
- **Никаких случайных изображений.** Не подставляй фотографии из интернета
  или чужих брендов. Пока реальный файл отсутствует в `public/images/...`,
  используется нейтральная заглушка (`components/ui/ProductImageSlot.tsx`),
  которая никогда не должна ломать сборку.
- **Не собирай exploded-view анимацию** из выдуманных деталей. Реальные
  части появятся в `public/images/dh20/exploded/` — до этого момента
  `ExplodedVacuumSection.tsx` остаётся статичной технической заготовкой.
- Не копировать напрямую стиль Apple/Dyson — у TIMAS свой визуальный язык:
  глубокий чёрный, графитовые секции, акцент шампань-металлик.

## Структура

- `app/` — маршруты App Router (страницы, layout, robots/sitemap, 404).
- `components/layout/` — шапка, мобильное меню, футер.
- `components/sections/` — секции главной страницы.
- `components/product/` — секции страницы товара.
- `components/ui/` — переиспользуемые примитивы (кнопка, слот изображения).
- `config/site.ts` — навигация и мета-конфигурация сайта.
- `data/` — типизированные данные (характеристики, детали exploded-view).
- `types/` — общие TypeScript-типы.

## Дизайн-токены

Определены в `app/globals.css` (`@theme inline`): `graphite-*` для секций,
`champagne-*` для акцентов, `bone-*` для текста на тёмном фоне. Не вводи
новые оттенки в компонентах напрямую — расширяй токены в `globals.css`.
