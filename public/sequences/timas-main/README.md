# TIMAS DH20 Ultra — scroll-кадры (hero-секция)

Сюда нужно положить реальные кадры для scroll-driven анимации на главной
странице (появление из темноты → приближение/поворот → exploded view →
сборка обратно).

## Куда класть файлы

```
public/sequences/timas-main/
  desktop/
    frame-0001.webp
    frame-0002.webp
    ...
    frame-0120.webp
  mobile/
    frame-0001.webp
    frame-0002.webp
    ...
```

- `desktop/` — кадры для широких экранов.
- `mobile/` — кадры для телефонов (может быть меньше кадров и/или ниже
  разрешение). Если папка `mobile/` пуста, сайт автоматически использует
  `desktop/`.

## Требования к файлам

- Формат: **WebP** или **AVIF** предпочтительно (лёгкий вес), также
  поддерживаются JPG и PNG.
- Имя файла должно содержать порядковый номер кадра (любое количество
  цифр, с ведущими нулями или без — `frame-1.webp`, `frame-0001.webp`,
  `001.avif` — подойдёт любой из этих вариантов).
- Кадры сортируются по числу в имени файла, а не по алфавиту — не нужно
  подгонять имена вручную.
- Количество кадров определяется автоматически по факту файлов в папке —
  ничего не нужно прописывать в коде.
- Соотношение сторон должно быть одинаковым у всех кадров одной папки.

## Что происходит, если кадров ещё нет

Пока обе папки пусты, главная страница не ломается: вместо
покадровой анимации показывается статичное реальное фото
(`public/images/dh20/vacuum-hero.webp`) с лёгким появлением при
прокрутке. Как только вы добавите файлы в `desktop/` (и опционально в
`mobile/`), сайт автоматически подключит покадровую анимацию — менять
код не нужно.
