# Mylamby — сайт бренда подгузников и трусиков

Русскоязычный сайт бренда детских подгузников и трусиков-подгузников
Mylamby (mylamby.ru). Помогает родителям познакомиться с брендом,
подобрать размер и перейти к покупке на маркетплейсе или в аптеке, а
также даёт магазинам и оптовым клиентам Северного Кавказа способ
связаться с компанией.

Построен по brand kit'у владельца бренда — см. «Источник правды» в
[CLAUDE.md](./CLAUDE.md).

## Стек

- [Next.js](https://nextjs.org) (App Router) + TypeScript
- Tailwind CSS v4
- Framer Motion (лёгкие UI-анимации: мобильное меню, Reveal при скролле)
- Lucide React (иконки)
- `sharp` — серверная проверка изображений (см. ниже)
- ESLint

## Запуск

```bash
npm install
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000).

Проверки перед коммитом:

```bash
npm run lint
npm run build
```

## Секции главной страницы

1. **Hero** — позиционирование («честный подгузник среднего сегмента»),
   ключевые цифры, кнопки «Выбрать размер» / «Где купить».
2. **Catalog** (`#catalog`) — подгузники и трусики-подгузники отдельными
   блоками, карточка на каждый размер.
3. **SizeGuide** (`#size-guide`) — таблица размеров, штук в упаковке и
   веса (весь столбец веса показывает «уточняется» — данных нет).
4. **AboutBrand** (`#about`) — позиционирование бренда + подтверждённые
   характеристики состава.
5. **QualityCare** (`#quality`) — сравнение «так не говорим / так
   говорим» по тону голоса бренда.
6. **WhereToBuy** (`#where-to-buy`) — кнопки на Wildberries/Ozon (пока
   отключены — ссылок нет) + упоминание аптек и офлайн-розницы.
7. **Wholesale** (`#wholesale`) — блок для магазинов и оптовых клиентов
   Северного Кавказа.
8. **FAQ** (`#faq`) — аккордеон с вопросами и ответами.
9. **FinalCTA** — финальный призыв к действию.

## Как подключить реальные материалы

Изображения автоматически заменяют заглушки, как только появляются по
нужному пути — правок кода не требуется. Проверка на сервере
(`lib/image-utils.ts`) не пропустит файл с шахматным узором, запечённым
вместо настоящей прозрачности — такой файл покажется как заглушка, а
предупреждение попадёт только в консоль сервера при разработке.

Нужные пути перечислены в `data/sizes.ts` (`image` у каждого размера и
категории) и в компонентах секций (`Hero.tsx`, `AboutBrand.tsx`) —
логотип кладите в `public/images/mylamby/logo/` и подключайте там, где
должен появиться логотип (сейчас используется только текстовый
логотип в `components/layout/Logo.tsx`).

Ссылки на маркетплейсы — в `config/commerce.ts`. Контакты (телефон,
почта, WhatsApp, Telegram, адрес, оптовые контакты) — в
`config/contacts.ts`. Домен сайта уже подтверждён в `config/site.ts`
(`url: "https://mylamby.ru"`).

## Характеристики продукта

Единственный источник — `data/brand-facts.ts`:

- Абсорбент SAP SANDIA
- 12-слойная конструкция
- Впитывающий слой — 71% состава
- Стандарт качества Japan Quality

## Размеры и количество в упаковке

Единственный источник — `data/sizes.ts`:

**Подгузники:** NB — 24 шт., S — 82 шт., M — 62 шт., L — 54 шт.,
XL — 50 шт., XXL — 46 шт.

**Трусики-подгузники:** M — 56 шт., L — 44 шт., XL — 38 шт., XXL — 28 шт.

Эти числа получены напрямую от владельца бренда в переписке — в brand
kit'е их нет. Диапазоны веса ребёнка не указаны нигде — сайт честно
показывает «уточняется» вместо придуманного диапазона. Добавляйте
`weightRange` к размеру в `data/sizes.ts` только после подтверждения
реальными цифрами.
